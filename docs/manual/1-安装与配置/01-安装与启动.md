# 安装与启动

先到官网下载安装，再打开 Cloak。

![官网首页下载区](assets/website-download-section.png)

## 1. 下载

打开 [CLOAK 官网下载中心](https://www.43cloak.com/#system-downloads)，在对应系统的版本卡片中点击下载。

- Windows：点 Windows 卡片下方的下载按钮。
- macOS：区分 Apple 芯片和 Intel 芯片，点击对应卡片中的下载按钮。
- Linux：点 Linux 卡片下方的下载按钮。

## 2. 安装

- Windows：双击安装包，按提示完成安装。
- macOS：打开 `.dmg`，把 Cloak 拖到“应用程序”文件夹。
- Linux：给 AppImage 加上可执行权限后打开。

## 3. 打开

- Windows：从桌面或开始菜单打开 Cloak。
- macOS：从“应用程序”打开 Cloak。
- Linux：从文件管理器或终端打开 Cloak。

## 4. 第一次打开

第一次打开后，会先进入初始引导页。

![初始引导页](assets/onboarding-welcome.png)

这一步的具体内容，继续看 [初始引导](02-初始引导.md)。
