# 人员管理

![人员管理列表页](./assets/users-list.png)

人员基础资料来自通讯录同步，部门显示在姓名下方。

## 列表页

真实组织后台的页面顶部主要有两个成员加入入口：

- `成员邀请码`
- `同步通讯录`

`增加成员` 只用于演示或其他管理作用域，不是组织管理员日常添加成员的入口。组织成员应通过通讯录同步或邀请码加入。

列表上方可以按姓名、分组、状态筛选，并查看席位占用。底部可以切换每页数量并翻页。

列表中可看到这些信息：

- 姓名和部门
- 角色
- 来源
- 状态
- 备注
- 分组

按权限不同，操作列可以进入 `团队模型 / SK`、编辑成员，或把成员移出当前组织。

## 人员详情

![人员详情抽屉](./assets/users-detail-drawer.png)

点击成员行，会打开人员详情。

这里可以查看：

- 所属分组
- 可用模型
- 模型点数额度
- 本月模型点数使用量

如果某项是按分组生效，页面会直接显示分组来源。

## 让成员加入组织

![增加成员弹窗](./assets/users-add-modal.png)

有两种常用方式：

1. 通讯录成员：点击 `同步通讯录`，同步完成后按姓名搜索。
2. 自助加入：点击 `成员邀请码`，创建限定有效期和可加入次数的邀请码，再把邀请码发给目标成员。

成员出现后，再进入编辑页设置分组、角色、模型和额度。

## 角色权限

![角色权限](./assets/users-role-permissions.png)

这里可以设置组织角色：

- 组织所有者
- 组织管理员
- 普通成员

只有 ROOT 或当前组织所有者可以维护组织角色。组织管理员可以按模块勾选权限。

每个模块分别控制：

- 查看
- 修改

## 模型点数额度

![模型点数额度](./assets/users-quota-settings.png)

这里可以给成员单独设置模型点数额度。

可以配置：

- 计费周期：每日、每月、总量
- 模型点数上限
- 是否清除个人额度

个人模型配置为空时，成员使用所属分组的可用模型。设置个人模型后，以个人配置为准。

## 团队模型 / SK

有模型修改权限的管理员，可以从人员列表进入 `团队模型 / SK`。

这里用于配置成员使用团队模型的方式，并查看或调整团队密钥状态。这个页签只在编辑现有成员时出现。

## 当前工作区权限

![当前工作区权限](./assets/users-workspace-permissions.png)

这里显示这个成员现在能进入哪些工作区。

每一行会列出：

- 工作区名称
- 权限
- 状态
- 最近更新

右上角可以查看权限变更记录，也可以刷新当前结果。

## 成员邀请码

![成员邀请码](./assets/users-invite-modal.png)

这里可以创建当前组织的邀请码，并查看已有邀请码列表。

创建时需要填写：

- 邀请码
- 名称
- 有效期
- 最大加入次数

下方列表可以按邀请码、名称和状态查询，也可以复制邀请码。

## 移出当前组织

![禁用确认](./assets/users-disable-modal.png)

真实组织后台的成员退出操作是 `移出当前组织`，不是禁用或删除全局账号。

执行前先确认：

- 成员姓名和当前组织无误。
- 工作区、文件或负责人职责已经交接。
- 不会移出最后一名组织所有者。

确认后，该成员不再拥有当前组织的访问权限，但全局账号和历史审计记录不会删除。
