# 工作区管理

![工作区列表](./assets/workspace-list.png)

这里可以查看和管理当前组织下的工作区。

## 列表页

页面顶部可以搜索工作区名称，也可以按状态筛选。

列表里直接能看到这些信息：

- 工作区名称
- 状态
- 类型
- 管理员
- 分组权限
- 描述
- 背景
- Skill
- Agent
- 文件数

右上角可以新建工作区。操作列会按工作区类型和状态显示文件、当前成员、群聊、模型策略、编辑或禁用入口。

## 创建工作区

![创建工作区类型](./assets/workspace-create-type.png)

新建时先选择工作区类型：

- 云端工作区
- 本地工作区

类型选定后，后面的配置会按这套类型展开。

- 云端工作区：可以配置 Agent，成员权限固定为“仅云端使用”，支持工作区群聊。
- 本地工作区：不配置 Agent，不显示群聊入口，成员权限分为“可查看”和“可编辑”；新建时会同时开通 Git 仓库。

类型创建后不能切换。

## 基本信息

![编辑工作区-基本信息](./assets/workspace-edit-basic.png)

在“基本信息”里可以改：

- 名称
- 描述
- 背景
- 单文件上限
- 状态

只有云端工作区显示文件访问方式，当前固定为 `临时授权（STS）`。

新建本地工作区时，页面会显示当前组织使用的 Git 仓库配置。没有可用配置时，需要先联系 CLOAK 团队或平台管理员完成开通。

## 权限配置

![编辑工作区-权限配置](./assets/workspace-edit-permissions.png)

这里可以给用户和工作组加授权。

不同工作区类型下，可选权限会不同。

## Skill 配置

![编辑工作区-Skill 配置](./assets/workspace-edit-skills.png)

这里可以勾选当前工作区启用的 Skill。

也可以设置 SkillHub 的使用方式。

## Agent 配置

![编辑工作区-Agent 配置](./assets/workspace-edit-agents.png)

云端工作区可以在这里绑定 Agent。

本地工作区会直接显示不需要配置 Agent。

## 当前成员

![当前成员](./assets/workspace-members.png)

这里看的是当前工作区实际生效的成员，不只是直接绑定的人。

列表里可以看到：

- 用户
- 角色
- 权限
- 是否直接绑定
- 来源工作组数
- 更新时间

## 云端工作区文件管理

![文件管理](./assets/workspace-file-manager.png)

云端工作区的文件管理左边是文件树，右边是文件详情。

可以直接做这些事：

- 新建文件
- 新建文件夹
- 导入文件夹
- 上传文件
- 删除选中文件
- 查看历史版本

选中文件后，可以在右侧直接编辑并保存。文件详情页里还能切到“修改记录”。

## 云端文件版本

![文件修改记录](./assets/workspace-file-history.png)

文件的修改记录会按版本列出来。

这里可以查看每次变更的说明，也可以恢复到旧版本。

当页面提示还有未更新的修改时，可以打开右侧的版本管理。

## 云端工作区版本管理

![工作区版本管理](./assets/workspace-version-drawer.png)

这里会把当前未更新的文件修改和历史工作区版本放在一起。

可以：

- 填写版本说明
- 更新版本
- 查看历史版本
- 恢复到某个工作区版本

## 本地工作区 Git 文件

本地工作区的文件入口显示为 `查看 Git 仓库`，不使用上面的云端文件编辑器。

这里可以：

- 切换并查看 TEAM 或成员 SELF 版本。
- 预览和下载文件。
- 有编辑权限时，向 TEAM 上传多个文件、导入文件夹、覆盖同名文件或删除文件。
- 查看每次写入生成的 Git 提交结果。

管理员写入只推进 TEAM 版本。成员 SELF 版本只供管理员查看、预览和下载；不能直接在 SELF 上写入。仓库未开通完成、工作区已禁用、仓库已归档或当前账号只有查看权限时，文件保持只读。

## 工作区群聊

![工作区群聊](./assets/workspace-message-rooms.png)

群聊只适用于云端工作区。本地工作区不会显示群聊入口。

群聊页会显示当前云端工作区下的群聊。

右上角可以新建群聊，列表里可以编辑或归档群聊。

当前没有群聊时，页面会显示空态。

## 创建群聊

![创建群聊](./assets/workspace-message-room-form.png)

创建群聊时填写：

- 群聊名称
- 说明
- 负责人

保存后，群聊就会归到这个工作区下。

## 禁用工作区

![禁用工作区](./assets/workspace-disable.png)

禁用前会先确认。

确认后，这个工作区会变为禁用状态。
