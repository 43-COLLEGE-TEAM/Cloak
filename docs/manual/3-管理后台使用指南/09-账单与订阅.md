# 账单与订阅

## 订阅概览

页面默认停在 `订阅概览`。

这里可以查看当前订阅状态和已使用情况，包括套餐、周期、起止时间，以及席位、模型点数、存储和工作区的占用。

右上角可以进入续费和升级。

## 套餐升级

`套餐升级` 里会展示可选套餐，方便做横向对比。

这里会显示套餐卡片、周期切换和基础对比信息。

## 加购资源

`加购资源` 里会放席位、点数、存储和工作区的扩充入口。

这里按资源类型展示扩充入口。

## 账单历史

`账单历史` 里可以查看过去的订单记录。

页面支持搜索、筛选和翻页。

## 确认订单

选择套餐或资源后，会进入确认订单页。

这里可以核对订单摘要、优惠信息、支付方式和发票信息。
