## 43 CLOAK 是什么

43 CLOAK 是一款面向企业全员的 AI 工作平台。它让企业的每一位员工，在日常工作中拥有一位懂业务的 AI 同事。

企业将自身积累的流程规范、岗位经验与行业 know-how 装入工作区，员工以对话方式调用工作区中的 AI 同事，由其协助完成日常业务。能力开放给员工使用，know-how 内核始终归属于组织。每一次调用都精确绑定至具体员工、具体工作区与具体业务产出，企业在 AI 上的投入由此与真实的生产现场逐一对应。员工在 AI 协同下形成的成果亦可经回流机制反哺工作区，使组织的智力资产在持续使用中持续增厚。

43 CLOAK 让企业的 AI 投入对管理者**管得住、用得对、留得下**，让 AI 对员工越用越懂业务、越懂岗位、越懂这家公司，适用于各行业、各规模企业的全员 AI 协作场景。

> 当前发布的桌面客户端已支持个人空间与企业空间，既可以作为个人 AI 工作入口，也可以接入企业团队协作场景。
>
> 企业版功能需要联系 CLOAK 团队配置并开通组织功能后才可使用；不开启企业功能，不影响个人版功能的正常使用。
>
> 本项目早期工作参考借鉴了 [TOKENICODE](https://github.com/yiliqi78/TOKENICODE) 进行迭代开发，在此致谢原作者（@小七姐，@Tiny）。
>
> Cloak 为闭源软件，仅提供安装包。

**当前已有功能：**

- 💬 **多个对话同时进行** — 可以同时开好几个话题，互不干扰，随时切换
- 📁 **直接处理文件** — 把文件拖进对话窗口，让 AI 帮你读、帮你总结、帮你分析
- 🏢 **个人空间 / 企业空间** — 个人资料与企业知识分开管理，团队协作边界更清晰
- 🪪 **飞书账号登录** — 企业成员可使用飞书账号登录，减少额外账号配置
- 🛠️ **管理后台** — 管理后台正在开发中，部分空间与成员管理能力已经可用
- 🤖 **选择不同的 AI 模型** — 根据需要，自由选择反应更快或能力更强的模型
- 🎨 **个性化界面** — 亮色、暗色随意切，还有多种配色与个人项目卡片皮肤可选
- 🧩 **工作搭子虚拟宠物** — 支持尺寸调节、转头宠物与自定义皮肤管理
- 💌 **问题反馈** — 设置中可以直接提交使用问题与改进建议
- 🌐 **中英文支持** — 界面语言可以随时切换

## 怎么使用

### 第一步：安装

- **Windows**：双击下载好的安装文件，一路点「下一步」就行
- **macOS**：打开下载的文件，把 Cloak 图标拖到「应用程序」文件夹
- **Linux**：右键下载的文件 → 属性 → 勾选「允许作为程序执行」，然后双击打开

### 第二步：登录与配置

第一次打开 Cloak，可以使用飞书账号登录；如果你使用个人空间，也可以点左下角的**设置**图标，找到「服务商」，选择你使用的平台，把 API Key 粘贴进去保存。

Cloak 内置了以下服务商，选好后点对应链接去注册获取 Key：

| 服务商 | 获取 API Key |
|--------|-------------|
| Anthropic（官方 Claude） | [前往获取](https://console.anthropic.com/account/keys) |
| 智谱 GLM | [前往获取](https://bigmodel.cn/usercenter/proj-mgmt/apikeys) |
| Kimi | [前往获取](https://platform.moonshot.cn/console/api-keys) |
| Kimi Code | [前往获取](https://www.kimi.com/code/console) |
| MiniMax | [前往获取](https://platform.minimaxi.com/user-center/basic-information/interface-key) |
| 通义千问 | [前往获取](https://bailian.console.aliyun.com/?apiKey=1) |
| OpenRouter | [前往获取](https://openrouter.ai/settings/keys) |
| 小米 MiMo | [前往获取](https://platform.xiaomimimo.com/) |

如果你已经有了 Key，直接粘贴进去就能用，不需要重新注册。

### 第三步：开始对话

点左上角的**新建对话**，在底部输入框里写下你想问的问题或想做的事，按回车发送，等 Claude 回复就行了。

**几个小技巧：**
- 有文件想让 AI 看？直接拖进对话框
- 输入 `/` 可以看到所有快捷命令
- 按 `Ctrl+K`（Windows）或 `Command+K`（Mac）可以快速搜索功能

## 常见问题 Q&A

### 企业版与账号

**Q：我只想自己用，需要开通企业版吗？**

A：不需要。个人版可以正常使用。企业工作区、组织成员、企业云端文件等功能，需要联系 CLOAK 团队配置开通后才会出现。

**Q：企业版开通后，我需要自己配置很多东西吗？**

A：通常不用。企业功能开通后，组织、成员、工作区和部分能力会由 CLOAK 团队或组织管理员配置。你只需要用对应账号登录。

**Q：左侧看不到企业工作区，是不是坏了？**

A：通常不是。请先确认你已经用飞书账号登录，并且你的组织已经开通企业功能、账号已被加入对应工作区。

**Q：飞书二维码过期或扫不上怎么办？**

A：关闭登录窗口重新打开，或点击刷新二维码；手机端确认使用的是飞书，并且网络正常。

**Q：换电脑后还能继续用吗？**

A：个人服务商 Key 需要在新电脑上重新配置；企业功能需要用同一个飞书账号登录，并且该账号仍在组织工作区内。

### 下载、安装与设备

**Q：我不知道该下载哪个安装包。**

A：Windows 选 Windows；Mac 先点左上角苹果图标 → 关于本机，看「芯片」一栏，M1 / M2 / M3 / M4 选 M 系列，Intel 就选 Intel。

**Q：Windows 打开后提示缺少 Git 或运行环境怎么办？**

A：先安装 Git for Windows，安装时一路默认即可。如果应用里提示安装基础组件，点安装并等待完成；失败时可以重试，或用管理员身份打开应用。

**Q：下载、安装或更新一直失败怎么办？**

A：先确认网络正常、磁盘空间足够，并暂时关闭会拦截安装包的安全软件。Windows 可以尝试右键安装包，选择“以管理员身份运行”。

**Q：电脑太旧会影响使用吗？**

A：会。内存太小、磁盘空间不足、系统版本太旧，都可能导致安装慢、打开慢或更新失败。建议关闭不用的软件，并保留足够磁盘空间。

**Q：macOS 提示没有权限访问文件怎么办？**

A：到「系统设置 → 隐私与安全性 → 完全磁盘访问权限」里给 Cloak 授权，然后重启应用再试。

### 对话与文件

**Q：点“新建对话”后，我应该输入什么？**

A：直接像和同事说话一样描述需求即可，比如“帮我总结这个文件”“把这段话改得正式一点”“帮我列一个执行计划”。

**Q：同一个问题可以开多个对话吗？会不会互相影响？**

A：可以。多个对话是分开的，适合把不同任务拆开处理。切换对话不会删除之前内容，但建议重要结果及时复制保存。

**Q：为什么有时 AI 回复很慢？**

A：可能是网络慢、模型服务忙、文件较大、问题较长，或当前模型本身响应较慢。可以先等一会儿，或换一个更快的模型再试。

**Q：输入 `/` 后出现很多命令，我一定要会用吗？**

A：不用。普通用户直接打字提问就可以。`/` 命令是给进阶用户快速操作用的，不会影响日常使用。

**Q：为什么提示“权限请求”或让我确认操作？**

A：这是为了避免 AI 自动改动文件或执行敏感操作。看清楚提示内容后再点允许；如果不确定，就点拒绝。

**Q：回退功能是做什么的？**

A：如果你发现对话走偏了，可以用回退回到前面的某一步。涉及文件改动时，请先确认自己是否真的要恢复旧状态。

**Q：怎么把一段对话保存下来？**

A：在对话界面里使用导出功能，可以把任务导出成 Markdown 或 JSON。普通用户一般选 Markdown 更方便查看。

**Q：新建对话、个人工作区、企业工作区有什么区别？**

A：新建对话只是开始一个新话题；个人工作区主要放你自己的本地项目和对话；企业工作区需要组织开通后使用，里面通常是团队共享资料和成员协作内容。

**Q：我把文件拖进去了，AI 没有按文件内容回答怎么办？**

A：先确认文件已经出现在输入框或对话里，再发送问题。文件太大、格式特殊、没有读取权限，或者文件还在下载中，都可能导致 AI 没有看到完整内容。

**Q：能不能一次拖很多文件？**

A：可以尝试，但不建议一开始就拖太多。文件越多，AI 需要处理的内容越多，速度会变慢，也更容易超出模型能处理的范围。

**Q：文件面板里看不到我的文件怎么办？**

A：检查你是不是选错了项目文件夹；如果文件夹被移动、改名或删除，需要重新选择。企业云端文件则需要先登录并进入对应企业工作区。

### 企业工作区与云端文件

**Q：企业文件能看到但打不开、不能上传，是为什么？**

A：这通常和工作区权限有关。有些账号只能浏览目录，不能读取内容或写入文件。需要联系组织管理员或 CLOAK 团队调整权限。

**Q：企业云端文件和我电脑里的文件有什么区别？**

A：企业云端文件属于组织工作区，通常是团队共享资料；你电脑里的文件只在本机。云端文件的查看、下载、上传会受企业权限控制。

**Q：云端文件显示“同步”“缓存”“冲突”是什么意思？**

A：可以简单理解为文件正在和本地副本对齐。如果看到冲突，先不要反复上传或删除，建议刷新后再试，或联系管理员确认哪个版本是正确的。

**Q：企业工作区里的成员头像有什么用？**

A：它帮助你确认这个工作区有哪些成员参与。是否能看到文件、读取内容或写入，仍然取决于账号权限。

### 模型、API Key 与网络

**Q：我没有 API Key，能不能用？**

A：企业用户通常由组织统一配置；个人用户需要在设置里填写自己的服务商 Key。如果不知道 Key 是什么，可以先联系服务商或你的组织管理员。

**Q：填了 Key 还是不能对话怎么办？**

A：检查三件事：Key 有没有复制完整；设置里是否选中了对应服务商；网络是否能访问该服务商。也可以换一个模型再试。

**Q：我不小心切到别的模型或服务商了怎么办？**

A：打开左下角设置，进入服务商或通用设置，重新选择你要使用的服务商和默认模型即可。

**Q：API 提供商里的“测试连接”失败，就一定不能用吗？**

A：不一定。有些服务商会限制测试请求来源。你可以确认 Key 和模型名没填错后，直接新建一个简单对话试试。

**Q：API Key 明明没错，为什么还是失败？**

A：除了 Key 本身，还可能是余额不足、套餐未开通、服务商限制地区、模型名称变化、请求太频繁，或服务商临时故障。可以去对应服务商后台检查状态。

**Q：为什么提示额度不足、模型不可用或请求失败？**

A：这通常来自模型服务商，不一定是 Cloak 的问题。请检查服务商账户余额、可用模型、账单状态和网络连接。

**Q：“思考强度”是不是越高越好？**

A：不一定。思考越深通常越慢、消耗也可能更高。普通总结、改写、问答用低或中就够；复杂分析再调高。

**Q：公司网络、校园网或代理会影响使用吗？**

A：会。部分网络会限制访问模型服务、GitHub、下载地址或二维码登录服务。可以换一个网络，或让网管放行相关访问。

**Q：开了 VPN、代理或安全软件后不能用了怎么办？**

A：先临时关闭代理或安全软件试一次，判断是不是它们拦截了连接或文件访问。公司电脑如果不能关闭，请联系 IT 管理员处理。

### 设置、更新与个性化

**Q：桌面宠物、主题、头像这些设置会影响 AI 能力吗？**

A：不会。这些只是界面和使用体验设置，不会改变 AI 的回答能力。

**Q：字体太小、界面太亮或太暗怎么办？**

A：打开左下角设置，在通用里调整字体大小、外观模式和主题颜色。

**Q：为什么设置在另一台电脑上没有同步？**

A：个人本地配置通常需要在新电脑重新设置；企业账号相关配置是否同步，取决于组织是否开通和配置了对应能力。

**Q：CLI 管理是什么？普通用户要管吗？**

A：它是 Cloak 正常运行需要的基础组件管理入口。普通用户通常只需要在提示安装、更新或修复时按按钮操作。

**Q：MCP 服务器是什么？需要配置吗？**

A：这是给进阶用户连接外部工具用的。普通聊天、读文件、企业工作区使用都不要求你配置 MCP。

**Q：更新后界面没变化怎么办？**

A：先完全退出 Cloak，再重新打开。如果仍然没有变化，到设置页检查更新，或重新下载安装包覆盖安装。

### 反馈与排查

**Q：遇到问题时，我应该怎么反馈才有用？**

A：尽量写清楚你点了哪里、想做什么、出现了什么提示，并附上截图。设置里的反馈页支持粘贴截图和选择文件。

**Q：反馈里要不要留下联系方式？**

A：建议留下邮箱、微信或飞书手机号。这样团队需要更多信息时可以联系你，不留也可以提交。

**Q：我担心自己误操作，怎么办？**

A：不确定的按钮先不要点，尤其是删除、覆盖、上传、允许权限这类操作。可以截图后咨询组织管理员或 CLOAK 团队。

## 反馈与建议

使用中遇到问题，或者有想要的新功能、改进建议，都可以在应用内直接反馈：

打开左下角的**设置**，进入**反馈**页面，填写你的问题或建议。你可以粘贴截图或选择文件，也可以留下邮箱、微信或飞书手机号，方便我们后续跟进。

![设置中的反馈页面](docs/screenshots/feedback.png)

如果是使用问题，尽量说清楚你在做什么、出现了什么情况、用的是哪个系统；如果是功能建议，直接描述你希望 Cloak 帮你完成什么即可。
