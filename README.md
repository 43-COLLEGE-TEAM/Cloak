## 43 CLOAK 是什么

43 CLOAK 帮助个人和企业把资料、流程、经验和日常任务放到一个 AI 工作入口里。你可以像和同事沟通一样提问，也可以把文件、项目资料和团队文档交给 AI 处理。

个人使用时，Cloak 可以作为本地项目和日常对话的 AI 助手。你可以选择一个项目文件夹，围绕里面的文件发起任务，让 AI 帮你阅读、总结、改写、分析或整理计划。

企业使用时，Cloak 可以连接企业工作区，让成员在授权范围内使用团队资料、企业文件和组织配置好的模型服务。企业版让 AI 不只服务个人，也能服务团队的资料、流程和管理要求。

当前桌面客户端已支持**个人工作区**与**企业工作区**。企业版功能需要联系 CLOAK 团队配置并开通组织能力；不开通企业版，也不影响个人功能的正常使用。

### 个人版能力

个人版适合自己使用，也适合作为本地项目的 AI 工作入口。不开通企业版，也可以正常使用以下能力。

- 💬 **多个任务同时进行** — 不同话题可以分开处理，互不打扰，随时切换回来继续
- 📁 **直接处理文件** — 把文件拖进对话窗口，让 AI 帮你读、总结、改写、提取重点或分析内容
- 🗂️ **本地文件管理** — 在**文件**面板搜索、预览、打开文件，也可以把文件插入到对话里继续提问
- 🎙️ **专注模式** — 用更安静的界面整理问题、查看文件和进行语音输入
- 🤖 **模型选择** — 根据任务需要选择更快或更强的模型
- 🔑 **API 提供商配置** — 在**设置 → API 提供商**填写 API Key，即可接入常用模型服务商
- ☁️ **云端模型列表更新** — 常用服务商和模型可从云端更新，减少手动维护成本
- 🚀 **初次配置引导** — 首次打开时引导完成基础设置和项目创建
- 🎨 **个性化界面** — 支持亮色 / 暗色、主题颜色、字体大小和项目卡片皮肤
- 🧩 **企业搭子** — 可在**设置**中管理企业搭子资源、缓存和显示尺寸
- 💌 **问题反馈** — 在**设置 → 反馈**提交问题描述、截图、文件和联系方式
- 🌐 **中英文界面** — 界面语言可随时切换，适合不同使用习惯

### 企业版能力

企业版包含客户端里的**企业工作区**和**云端**文件，也包含给管理员使用的管理后台。它不需要让每个成员自己配置 AI，而是让组织统一管理成员、资料、模型、用量和权限。

- 🪪 **成员登录与组织管理** — 成员可以用飞书登录，进入自己有权限的**企业工作区**；加入多个组织的用户，也可以在不同组织之间切换
- 🏢 **工作区资料管理** — 企业可以把项目资料、流程文档、共享文件放到工作区，成员在**云端**面板里查看、下载和使用这些资料
- 🧭 **个人工作区 / 企业工作区分开** — 个人资料和企业资料分开管理，自己的项目和团队资料不会混在一起
- 🔐 **权限分配与提示** — 管理员可以按用户、分组和工作区设置谁能看目录、谁能读取内容、谁能写入文件；客户端也会提示当前账号能做什么，减少误操作
- 🤖 **模型统一管理** — 组织可以统一配置可用模型，并按团队或成员开放，普通成员不需要自己理解复杂的模型服务配置
- 📊 **用量和成本查看** — 管理员可以通过数据看板、模型用量、成员排行、账单与订阅，了解团队是否真正用起来，以及资源消耗集中在哪里
- 🧾 **版本和操作追溯** — 管理员可以查看客户端版本、审计日志和关键操作记录，用来排查版本、权限、额度、工作区变化等问题

不开通企业版时，个人功能可以正常使用。企业工作区、云端文件、组织权限和后台管理等能力，需要组织开通后才会出现。

## 3 分钟上手

### 第一步：安装

- **Windows**：双击下载好的安装文件，按提示完成安装。
- **macOS**：打开下载的文件，把 Cloak 图标拖到“应用程序”文件夹。
- **Linux**：优先使用通用版；如果是 AppImage，右键文件进入属性，允许作为程序执行后打开。

### 第二步：登录或配置 API 提供商

企业用户可以使用飞书账号登录。登录后，如果你所在组织已经开通企业功能，就可以看到对应企业工作区。

个人用户可以打开左下角**设置**，进入**API 提供商**，选择常用模型服务商，并按提示填写 **API Key**。Cloak 内置了以下常用服务商入口：

| 服务商 | 获取 API Key |
|--------|-------------|
| 小米 MiMo Token Plan | [前往获取](https://platform.xiaomimimo.com/#/console/plan-manage) |
| 小米 MiMo | [前往获取](https://platform.xiaomimimo.com/) |
| Anthropic（官方 Claude） | [前往获取](https://console.anthropic.com/account/keys) |
| 智谱 GLM | [前往获取](https://bigmodel.cn/usercenter/proj-mgmt/apikeys) |
| Kimi | [前往获取](https://platform.moonshot.cn/console/api-keys) |
| Kimi Code | [前往获取](https://www.kimi.com/code/console) |
| MiniMax | [前往获取](https://platform.minimaxi.com/user-center/basic-information/interface-key) |
| 通义千问 | [前往获取](https://bailian.console.aliyun.com/?apiKey=1) |

如果你已经有可用 API Key，直接粘贴保存即可，不需要重新注册。

### 第三步：开始对话

如果还没有选择项目，可以先在欢迎界面点击**选择文件夹**。进入项目后，点击左上角**新建任务**，在底部输入框里写下你想完成的事，按回车发送。需要 AI 看文件时，把文件拖进对话框再提问。

企业用户可以先选择企业工作区，再基于团队资料和云端文件发起对话。

**几个小技巧：**

- 同一个项目可以开多个对话，分别处理不同任务。
- 输入 `/` 可以看到快捷命令，不会用也不影响正常提问。
- 按 `Ctrl+K`（Windows）或 `Command+K`（Mac）可以快速搜索功能。

## 常见问题 Q&A

### 企业版与账号

**Q：我只想自己用，需要开通企业版吗？**

A：不需要。个人功能可以正常使用。企业工作区、组织成员、企业云端文件等能力，需要联系 CLOAK 团队配置开通后才会出现。

**Q：企业版开通后，我需要自己配置很多东西吗？**

A：通常不用。企业功能开通后，组织、成员、工作区和部分服务商配置会由 CLOAK 团队或组织管理员配置。你只需要用对应账号登录。

**Q：左侧看不到企业工作区，是不是坏了？**

A：通常不是。请先确认你已经用飞书账号登录，并且组织已经开通企业功能、你的账号也已经加入对应工作区。

**Q：飞书二维码过期或扫不上怎么办？**

A：关闭登录窗口重新打开，或点击刷新二维码。也请确认手机端使用的是飞书，并且网络正常。

**Q：换电脑后还能继续用吗？**

A：可以。个人用户需要在新电脑上重新配置服务商；企业用户用同一个飞书账号登录，并确保账号仍在组织工作区内。

### 下载、安装与设备

**Q：我不知道该下载哪个安装包。**

A：Windows 选 Windows；Mac 先点击屏幕左上角的苹果图标，选择“关于本机”，查看“芯片”一栏，M1 / M2 / M3 / M4 选 M 系列，Intel 选 Intel。Linux 不确定时先选通用版。

**Q：Windows 打开后提示缺少 Git 或运行环境怎么办？**

A：按应用里的提示安装基础组件即可。也可以先安装 Git for Windows，安装时保持默认选项。

**Q：下载、安装或更新一直失败怎么办？**

A：先确认网络正常、磁盘空间足够，并暂时关闭会拦截安装包的安全软件。Windows 可以尝试右键安装包，选择“以管理员身份运行”。

**Q：电脑太旧会影响使用吗？**

A：会。内存太小、磁盘空间不足、系统版本太旧，都可能导致安装慢、打开慢或更新失败。建议关闭不用的软件，并保留足够磁盘空间。

**Q：macOS 提示没有权限访问文件怎么办？**

A：到“系统设置 → 隐私与安全性 → 完全磁盘访问权限”里给 Cloak 授权，然后重启应用再试。

### 对话与文件

**Q：点“新建任务”后，我应该输入什么？**

A：直接像和同事说话一样描述需求即可，比如“帮我总结这个文件”“把这段话改得正式一点”“帮我列一个执行计划”。

**Q：同一个问题可以开多个对话吗？会不会互相影响？**

A：可以。多个对话是分开的，适合把不同任务拆开处理。切换对话不会删除之前内容，但重要结果建议及时保存。

**Q：为什么有时 AI 回复很慢？**

A：可能是网络慢、模型服务忙、文件较大、问题较长，或当前模型本身响应较慢。可以先等一会儿，或换一个更快的模型再试。

**Q：输入 `/` 后出现很多命令，我一定要会用吗？**

A：不用。普通用户直接打字提问就可以。`/` 命令用于快速操作，不会影响日常使用。

**Q：为什么提示“权限请求”或让我确认操作？**

A：这是为了避免 AI 自动改动文件或执行敏感操作。看清楚提示内容后再点允许；如果不确定，就点拒绝。

**Q：回退功能是做什么的？**

A：如果你发现对话走偏了，可以用回退回到前面的某一步。涉及文件改动时，请先确认自己是否真的要恢复旧状态。

**Q：怎么把一段对话保存下来？**

A：在对话界面里使用导出功能，可以把任务导出成 Markdown 或 JSON。普通用户一般选 Markdown，更方便查看和分享。

**Q：新建任务、个人工作区、企业工作区有什么区别？**

A：新建任务只是开始一个新话题；个人工作区主要放你自己的本地项目和任务；企业工作区需要组织开通后使用，通常用于团队共享资料和协作内容。

**Q：我把文件拖进去了，AI 没有按文件内容回答怎么办？**

A：先确认文件已经出现在输入框或对话里，再发送问题。文件太大、格式特殊、没有读取权限，或文件还在下载中，都可能导致 AI 没有看到完整内容。

**Q：能不能一次拖很多文件？**

A：可以尝试，但不建议一开始就拖太多。文件越多，AI 需要处理的内容越多，速度会变慢，也更容易超出模型能处理的范围。

**Q：文件面板里看不到我的文件怎么办？**

A：检查你是不是选错了项目文件夹；如果文件夹被移动、改名或删除，需要重新选择。企业云端文件则需要先登录并进入对应企业工作区。

### 企业工作区与云端文件

**Q：企业文件能看到但打不开、不能上传，是为什么？**

A：这通常和工作区权限有关。有些账号只能浏览目录，不能读取内容或写入文件。需要联系组织管理员或 CLOAK 团队调整权限。

**Q：企业云端文件和我电脑里的文件有什么区别？**

A：企业云端文件属于组织工作区，通常是团队共享资料；你电脑里的文件只在本机。云端文件的查看、下载、上传会受企业权限控制。

**Q：云端文件显示“同步”“缓存”“冲突”是什么意思？**

A：可以简单理解为文件正在和本地副本对齐。如果看到冲突，先不要反复上传或删除，建议刷新后再试，或联系管理员确认哪个版本是正确的。

**Q：企业工作区里的成员头像有什么用？**

A：它帮助你确认这个工作区有哪些成员参与。是否能看到文件、读取内容或写入，仍然取决于账号权限。

### 模型、API Key 与网络

**Q：我没有 API Key，能不能用？**

A：企业用户通常由组织统一配置。个人用户需要在设置里填写自己的服务商 API Key；如果不知道去哪里获取，可以联系服务商或组织管理员。

**Q：填了 API Key 还是不能对话怎么办？**

A：检查三件事：API Key 有没有复制完整；设置里是否选中了对应服务商；网络是否能访问该服务商。也可以换一个模型再试。

**Q：我不小心切到别的模型或服务商了怎么办？**

A：打开左下角设置，进入 API 提供商或通用设置，重新选择你要使用的服务商和默认模型即可。

**Q：API 提供商里的“测试连接”失败，就一定不能用吗？**

A：不一定。有些服务商会限制测试请求来源。确认 API Key 和模型名称没填错后，可以新建一个简单对话试试。

**Q：API Key 明明没错，为什么还是失败？**

A：还可能是余额不足、套餐未开通、服务商限制地区、模型名称变化、请求太频繁，或服务商临时故障。可以去对应服务商后台检查状态。

**Q：为什么提示额度不足、模型不可用或请求失败？**

A：这通常来自模型服务商，不一定是 Cloak 的问题。请检查服务商账户余额、可用模型、账单状态和网络连接。

**Q：“思考强度”是不是越高越好？**

A：不一定。思考越深通常越慢，消耗也可能更高。普通总结、改写、问答用低或中就够；复杂分析再调高。

**Q：公司网络、校园网或代理会影响使用吗？**

A：会。部分网络会限制访问模型服务、GitHub、下载地址或二维码登录服务。可以换一个网络，或让网管放行相关访问。

**Q：开了 VPN、代理或安全软件后不能用了怎么办？**

A：先临时关闭代理或安全软件试一次，判断是不是它们拦截了连接或文件访问。公司电脑如果不能关闭，请联系 IT 管理员处理。

### 设置、更新与个性化

**Q：桌面宠物、主题、头像这些设置会影响 AI 能力吗？**

A：不会。这些只是界面和使用体验设置，不会改变 AI 的回答能力。

**Q：字体太小、界面太亮或太暗怎么办？**

A：打开左下角设置，在通用里调整字体大小、外观模式和主题颜色。

**Q：为什么设置在另一台电脑上没有同步？**

A：个人本地配置通常需要在新电脑重新设置；企业账号相关配置是否同步，取决于组织是否开通和配置了对应能力。

**Q：CLI 管理是什么？普通用户要管吗？**

A：它是 Cloak 正常运行需要的基础组件管理入口。普通用户通常只需要在提示安装、更新或修复时按按钮操作。

**Q：MCP 服务器是什么？需要配置吗？**

A：这是给进阶用户连接外部工具用的。普通聊天、读文件、企业工作区使用都不要求你配置 MCP 服务器。

**Q：更新后界面没变化怎么办？**

A：先完全退出 Cloak，再重新打开。如果仍然没有变化，到设置页检查更新，或重新下载安装包覆盖安装。

### 反馈与排查

**Q：遇到问题时，我应该怎么反馈才有用？**

A：尽量写清楚你点了哪里、想做什么、出现了什么提示，并附上截图。设置里的反馈页支持粘贴截图和选择文件。

**Q：反馈里要不要留下联系方式？**

A：建议留下邮箱、微信或飞书手机号。这样团队需要更多信息时可以联系你，不留也可以提交。

**Q：我担心自己误操作，怎么办？**

A：不确定的按钮先不要点，尤其是删除、覆盖、上传、允许权限这类操作。可以截图后咨询组织管理员或 CLOAK 团队。
